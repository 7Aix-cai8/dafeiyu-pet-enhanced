# 大肥鱼桌宠 · 增强版 🐋

一个 Windows 优先、本地优先的桌面宠物。她会在桌面上满屏散步、回应鼠标互动、在你写代码或看视频时搭话，还能看你一眼屏幕然后顺着画面跟你聊两句。

本仓库是**在原作者项目基础上做的个人增强版**，下面明确标注了来源和新增内容。

## 本增强版新增 / 改造的功能

### 1. 看图点评（视觉点评）
- **全后台**截图 → 本地比对画面是否变化（**0 成本**）→ 只有变化了才调用视觉模型
- 用 `deepseek-flash`（唯一支持看图的模型），1568px 高清，**约 1 秒**返回
- 提示词要求她**先读懂画面上的字**，再**挑一个有趣的细节**随口聊，而不是复述画面
- **点评记忆**：最近 50 条点评 + 最近 10 分钟屏幕活动时间线，避免重复、能接前文
- **防重复**：上一条说过的话会单独喂给模型，要求换角度
- **长度自适应**：槽点多时可以说到 70 字，卡片按文字自动撑开
- **停留时间随字数**：2 字停 4 秒，50 字停 19 秒
- 卡片**跟随宠物移动**，优先放在她**头顶上方**，放不下才放旁边
- **点评历史**：设置里点「◷」看最近 3 条
- 30 秒冷却、每日 500 次上限（约 ¥1.5/天）

### 2. 本地感知增强
- 场景识别扩展到：视频、游戏直播、代码、文档、论文、写题、AI 对话
- 新增**写题 / 作业**分类与专属评价台词
- **标题感知**：从窗口标题里抽出正在看的内容名，并塞进台词
  （例如「陈子豪绝地求生-虎牙直播 和另外 2 个页面 - 个人 - Microsoft Edge」→ 只保留内容名）
- 台词库大幅扩充（视频 / 编码 / 文档 / GitHub / 日常 / 写题，各四种人格）

### 3. 今日用量显示（点她的脸）
- 读取本机 DeepSeek Harness 的会话数据，显示**今日 token 用量**
- 按官方单价换算**人民币估算**，并标注**峰时 / 谷时**
- 支持 `deepseek-flash` 与 `deepseek-v4-pro` 分别计价

### 4. 任务清单（双击宠物打开）
- 每页 **3 条**，带翻页；任务卡**深浅不同的浅色底**，2px 描边区分层次
- 单击右侧按钮 → **绿色打勾动画** → 文字变浅加删除线并移到末尾
- 每条任务旁边有「✎」**编辑按钮**，也可双击文字直接改
- **拖动任务**可调整优先级
- 新任务插入到「未完成任务之后、已完成任务之前」
- 面板**可拖动**，并且**根据宠物位置自动出现在她两侧**
- 数据存本地，**关机重启不丢**

### 5. 设置面板重做
- 整体改为**浅色主题**，和任务清单、点评卡片同一套视觉
- 开关改为**圆形开关**（自绘，整行可点）
- 「看图点评」「全屏隐藏」提到**第一屏**，不用展开
- **点面板外面自动关闭**
- 新增「点评历史」入口按钮

### 6. 满屏漫游
- 不再只沿屏幕底部走，可以**在整个屏幕内自由移动**
- 上下坡时保持四帧侧面行走动画，并用**身体倾斜**表现坡度

### 7. 其他
- 气泡字号放大，长句不再被截断
- 普通对话气泡与点评卡片**互斥**，点评优先
- 开机自启会自动校正指向当前运行的程序

## 运行

```bash
pip install -r requirements.txt
python main.py
```

打包为单文件 exe（需要 PyInstaller）：

```bash
pyinstaller --onefile --windowed --name "DaFeiYu-Pet" --icon icon.ico \
  --add-data "assets;assets" --add-data "sprites;sprites" main.py
```

> `assets/processed` 是从 `sprites/` 预先处理好的切图；如需重新生成，运行 `python preprocess.py`。

**看图点评需要**：能访问 `api.deepseek.com`，并且 `~/.dsh/.credentials.yaml` 里存在 `DEEPSEEK_API_KEY`（或自行改成自己的 key）。
